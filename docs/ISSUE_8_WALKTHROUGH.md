# Upload and review

Use the [local setup](../START_HERE.md#run-locally) with fictional DOCX files.

1. Add a fictional NDA or customer-order standard through **References**. Local uploads become active standards; this does not verify legal authority.
2. Choose **Upload DOCX contracts** and select one file or a batch of up to 20.
3. Open a result. Where enough source context identifies a suitable active reference, comparison has already run. Check the proposed standard, original files and differences.
4. Confirm reference applicability separately. It does not accept the contract or invent a previous human confirmation.
5. Open findings, record assessments, then accept or flag the contract as appropriate. Inspect the history.

If no suitable reference can be selected, the original stays in the queue and **Comparison not run** explains the reason. Do not treat an unmatched file as a clean comparison.

Customer-order results describe section and wording differences, not the meaning of quantities, fees or legal terms. PDFs are outside this version. The public demo cannot run this workflow.

See [intake details](EXPLICIT_REFERENCE_UPLOAD.md) and [integration evidence](INTEGRATED_REVIEW_ACCEPTANCE.md).
